# 契約3（OctantPath ↔ OctantCompass）の要求と応答の例

[契約3（OctantPath ↔ OctantCompass）](../../mod-api.md)の要求と応答の例です。2026-10-07 に承認し、契約3 の一部として扱います。OctantPath（C#）と OctantCompass（pytest）の両方のテストがこの例を読みます。

- 例は [OpenAPI](../../mod-api.openapi.yaml) に合います。どの例がどのスキーマに合うかは [examples/schemas.json](../schemas.json) にあり、[tools/check.py](../../../tools/check.py) が確かめます
- 項目の形と意味は、OpenAPI と、そこから参照するスキーマの `description` にあります
- `hash` はすべて作った値で、実在のマップではありません
